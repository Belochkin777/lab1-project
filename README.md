# Учебный трекер задач

Небольшой консольный проект на Python для освоения Git и базовой структуры программного репозитория. Приложение позволяет вывести список задач и добавить новую задачу в локальный файл.

## Идея проекта

Трекер помогает быстро записывать учебные и личные задачи в терминале без отдельного сервиса или аккаунта.

## Целевая аудитория

Студенты и начинающие разработчики, которые изучают Python и контроль версий.

## Технологии

- Python 3.12
- Стандартная библиотека Python

## Установка и запуск

Установите Python 3.12 или новее, затем из каталога проекта выполните:

```bash
python app.py list
python app.py add "Подготовить лабораторную"
```

Список задач хранится в `tasks.json` рядом с приложением. Файл данных не добавляется в Git.
